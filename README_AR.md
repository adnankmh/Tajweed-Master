# Tajweed Master Pro V16 Ultra Professional

هذه النسخة V16 تركز على تحسين تجربة المصحف والتلاوة والتخصيص:

- تفعيل اتجاه ومحاذاة النص من اليمين إلى اليسار عند اختيار اللغة العربية في التطبيق والمصحف.
- خلفية صفحة المصحف أصبحت اختيارية من الإعدادات ومن الشريط العلوي، ويمكن اختيار لون مستقل عن الثيم العام.
- إضافة مشغل تلاوة داخل صفحة المصحف نفسها، مع اختيار القارئ وتشغيل السورة مباشرة وظهور نور متحرك مع الآيات.
- استمرار الصوت ونور التتبع أثناء التنقل بين صفحات التطبيق.
- تحسين تطبيق نوع الخط وحجم الخط على الواجهة والمصحف، مع ملاحظة أن بعض خطوط الويب تعتمد على توفر الخط في الجهاز/المتصفح.
- توسيع الأسئلة والامتحانات بإضافة بنك أسئلة تلقائي أكبر وتصحيح أخطاء مفصل.
- زيادة الشروحات والتدريبات المتقدمة داخل صفحات الأحكام مع قائمة مراجعة الأداء.
- الحفاظ على تلوين أحكام التجويد على الحروف نفسها بصريًا دون تكسير الكلمات قدر الإمكان.

## الرفع على GitHub

1. فك الضغط.
2. افتح المجلد حتى ترى: `lib`, `assets`, `web`, `.github`, `pubspec.yaml`.
3. ارفع الملفات إلى مستودع GitHub الحالي عبر:
   `Code > Add file > Upload files`
4. اكتب رسالة commit مثل:
   `Upload V16 Ultra Professional Mushaf`
5. انتظر GitHub Actions حتى يصبح الضوء أخضر.

## ملاحظات مهمة

- تلوين الأحكام تعليمي خوارزمي ويحتاج مراجعة علمية متخصصة قبل نشره كتطبيق مصحف تجويد معتمد.
- تشغيل الصوت يعتمد على روابط MP3 خارجية، لذلك يحتاج اتصال إنترنت إلى حين إضافة تحميل الصوت Offline كاملًا.
- إدارة المحتوى الحقيقية عبر Firebase/Supabase ما تزال تحتاج إعداد مشروع سحابي فعلي من حساب المالك.
