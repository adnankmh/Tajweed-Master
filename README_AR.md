# Tajweed Master Pro V17 — Monetized Admin Pro

هذه نسخة Flutter Web محسّنة للنشر عبر GitHub Pages، تركّز على:

- إجبار المصحف على اتجاه ومحاذاة RTL من اليمين إلى اليسار.
- تحسين رسم ألوان أحكام التجويد على الحروف نفسها دون تكسير الكلمات قدر الإمكان.
- إضافة مساحات إعلانات جاهزة داخل التطبيق مع إمكانية إظهارها أو إخفائها من لوحة الإدارة.
- تجهيز AdSense للويب عبر `web/ads.txt` ووسوم جاهزة في `web/index.html`، مع ضرورة استبدال Publisher ID الحقيقي بعد قبول AdSense.
- لوحة إدارة داخل التطبيق تظهر بعد تسجيل الدخول:
  - UserName: `Adnan`

- نشر لوحة الإدارة المستقلة داخل `/admin/` عند نجاح GitHub Actions.
- Workflow جديد أنظف لتقليل مشاكل GitHub Pages والتعامل مع النشر الرسمي.

## ملاحظات مهمة عن الإعلانات

تم تجهيز مساحات الإعلانات داخل التطبيق وتجهيز ملفات الويب، لكن الربح الحقيقي يتطلب:

1. حساب Google AdSense للويب أو Google AdMob لتطبيق Android/iOS.
2. استبدال `pub-XXXXXXXXXXXXXXXX` في `web/ads.txt` برقم الناشر الحقيقي.
3. إضافة AdSense script الحقيقي أو لاحقًا إضافة `google_mobile_ads` عند بناء Android/iOS.
4. يفضّل عدم عرض الإعلانات داخل صفحة المصحف أثناء التلاوة احترامًا لتجربة القراءة.
